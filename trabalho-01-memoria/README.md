# Trabalho 1 — Sistema de Tarefas em Memória

Projeto com Node.js e Express. Dados armazenados em memória.

## Como executar
```bash
npm install
npm start

Acesse: http://localhost:3001/tasks
Rotas
Tabela
Método	Rota	O que faz
GET	/tasks	Listar todas

PUT	/tasks/:id	Atualizar
DELETE	/tasks/:id	Remover
